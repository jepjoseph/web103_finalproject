## Reflection

### 1. What went well during this unit?

Our group made progress organizing the Local Bloom project for collaborative development. We established a shared GitHub organization repository, prepared our project pitch, and created a GitHub Project board to track development tasks. We also created seven GitHub issues covering frontend setup, backend setup, database design, API development, and user interface implementation. These steps helped us organize our responsibilities and prepare for the development phase.

### 2. What were some challenges your group faced in this unit?

One challenge was learning how GitHub repositories, Projects, issues, and milestones work together. We also encountered difficulties sharing our GitHub Project board directly with the CodePath grading account. Although we made the board publicly accessible, we have not yet confirmed explicit reviewer access. Coordinating frontend, backend, and database development is another challenge we are preparing to address.

### Did you finish all of your tasks in your sprint plan for this week? If you did not finish all of the planned tasks, how would you prioritize the remaining tasks on your list?

We completed several project-management and preparation tasks, including creating the Project board and development issues. However, we still need to verify which development tasks have been completed and tested. We plan to prioritize establishing a working frontend and backend, connecting the PostgreSQL database, and implementing the core event listing and detail functionality before moving to more advanced features.

### Which features and user stories would you consider “at risk”? How will you change your plan if those items remain “at risk”?

Potentially at-risk features include multi-criteria search with distance filtering, community spot submissions, and the integration between the frontend and backend. These features may require additional development and testing. If they remain at risk, we will prioritize the required baseline functionality, divide larger tasks into smaller GitHub issues, and postpone optional enhancements until the core application is stable.

### 5. What additional support will you need in upcoming units as you continue to work on your final project?

Our group would benefit from additional guidance on GitHub Project management, particularly milestone completion and granting access to the CodePath grading account. Technical feedback on PostgreSQL integration, API testing, and deploying our React and Express application to Render would also help us complete the project successfully.
