# User Stories

Reference the Writing User Stories final project guide in the course portal for more information about how to complete each of the sections below.

## Outline User Roles

1. **Creative Seeker**: A local resident, maker, or art enthusiast browsing the directory to discover independent craft shops, art cafes, bookstores, and creative workshops that fit their budget and location.
2. **Business Owner / Event Organizer**: A verified proprietor of an independent creative space or an organizer hosting hands-on workshops who creates, manages, and updates their directory listings and event schedules.

## Draft User Stories

1. As a Creative Seeker, I want to filter listings by budget tier ($ to $$$), so that I can discover activities, workshops, and materials that fit my financial limits.
2. As a Creative Seeker, I want to filter spaces by activity type, so that I can quickly find specific creative experiences.
3. As a Creative Seeker, I want to filter listings by distance radius, so that I can find creative spots and shops in my immediate neighborhood.
4. As a Creative Seeker, I want to click a listing card to open a slide-out modal preview, so that I can check essential venue hours and tags without losing my place in the catalog.
5. As a Creative Seeker, I want to view a dedicated dynamic detail page for a venue or event, so that I can see the complete physical address, operating schedule, and upcoming workshop calendar.
6. As a Business Owner, I want to submit a new venue listing through an intuitive form, so that local makers can discover my studio or retail shop.
7. As an Event Organizer, I want to post a new creative workshop with event dates, times, and admission costs, so that interested attendees can plan to join.
8. As a Business Owner, I want to edit my existing listing details, so that visitors always have up-to-date business hours and inventory focus.
9. As an Event Organizer, I want to assign multiple tags to my listing via a join table, so that users browsing either cafes or workshop studios can find my hybrid space.
10. As an Event Organizer, I want to delete past or cancelled workshops, so that outdated listings do not clutter the directory.
11. As a Creative Seeker, I want to sort search results by nearest distance, lowest price tier, or alphabetically, so that I can organize listings according to my immediate priorities.
12. As a Business Owner, I want to upload storefront and workshop photos directly to cloud storage when creating my listing, so that prospective visitors can get a clear visual preview of my creative space.
