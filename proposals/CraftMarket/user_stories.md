# User Stories

Reference the Writing User Stories final project guide in the course portal for more information about how to complete each of the sections below.

**Project:** CraftMarket — Option A (Proposed)

## Outline User Roles

1. **Buyer:** A user who explores handmade products, searches product listings, and saves products they are interested in.

2. **Seller:** An independent creator who establishes a shop profile and publishes and manages handmade product listings.

## Draft User Stories

1. As a buyer, I want to create an account, so that I can save products I am interested in.

2. As a buyer, I want to sign in to my account, so that I can access my saved products across visits.

3. As a seller, I want to register for a seller account, so that I can showcase my handmade products.

4. As a seller, I want to create a shop profile, so that buyers can learn about my business and the products I create.

5. As a seller, I want to add a product listing with a name, description, price, and image, so that buyers can discover my products.

6. As a seller, I want to edit my product listings, so that I can keep product information accurate.

7. As a seller, I want to delete products I no longer offer, so that buyers only see my current listings.

8. As a buyer, I want to browse products by category, so that I can discover handmade items that interest me.

9. As a buyer, I want to search products by keyword, so that I can find specific items quickly.

10. As a buyer, I want to filter products by price, so that I can discover items within my budget.

11. As a buyer, I want to view detailed product information, so that I can learn more about an item before deciding whether to save it.

12. As a buyer, I want to save products to my favorites, so that I can easily find them again later.

13. As a buyer, I want to view my favorite products in one place, so that I can compare items I am interested in.

14. As a buyer, I want to remove products from my favorites, so that my saved collection stays organized.

15. As a buyer, I want to visit a seller's shop profile, so that I can discover other products from the same creator.
