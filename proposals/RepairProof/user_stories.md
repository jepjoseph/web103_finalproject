# User Stories

Reference the Writing User Stories final project guide in the course portal for more information about how to complete each of the sections below.

**Project:** RepairProof — Option B (Proposed)

## Outline User Roles

1. **Tenant:** A person renting a home who wants to document home or appliance repairs, organize expenses, and prepare supporting records for possible reimbursement requests to a landlord.

2. **Homeowner:** A person who owns a home and wants to maintain a history of property repairs, track expenses, and organize supporting documents for financial or tax-related recordkeeping.

## Draft User Stories

1. As a tenant, I want to create a property record for my rental home, so that I can organize repairs associated with that property.

2. As a homeowner, I want to register my property, so that I can maintain a centralized history of home repairs and maintenance.

3. As a tenant, I want to create a repair record, so that I can document a problem I repaired or paid to have repaired.

4. As a homeowner, I want to record repairs and improvements, so that I can keep a history of work completed on my property.

5. As a tenant, I want to describe the original problem and the work performed, so that I can explain why the repair was necessary.

6. As a homeowner, I want to record repair dates and descriptions, so that I can review when maintenance was completed.

7. As a tenant, I want to record the cost of materials and labor, so that I can document how much I spent on a repair.

8. As a homeowner, I want to track expenses associated with each repair, so that I can understand the cost of maintaining my property.

9. As a tenant, I want to attach receipts and before-and-after photographs to a repair record, so that I can preserve supporting evidence for a reimbursement request.

10. As a homeowner, I want to attach invoices and receipts to repair records, so that I can organize supporting documents for future reference.

11. As a tenant, I want to edit a repair record, so that I can correct or update its details.

12. As a homeowner, I want to delete an incorrect or duplicate repair record, so that my maintenance history remains accurate.

13. As a tenant, I want to browse and filter my repair history by property, category, or date, so that I can quickly locate a specific repair.

14. As a homeowner, I want to view a summary of repair expenses, so that I can understand how much I have spent maintaining my property.

15. As a tenant, I want to prepare a summary of a repair and its expenses, so that I can present organized supporting information when requesting reimbursement from my landlord.

16. As a homeowner, I want to prepare a summary of repair and improvement expenses, so that I can share organized records with a tax professional when needed.

## Notes on Scope

These stories describe user needs, not completed functionality.

For the initial version, supporting evidence may be stored as document or image references rather than through full cloud file uploads.

Preparing an expense summary does not determine whether an expense is legally reimbursable or tax-deductible.

The final feature list will be refined after the group evaluates RepairProof against CraftMarket.
